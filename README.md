Cohort Analysis and Retention Metrics
📌 Описание проекта
Проект посвящен проведению когортного анализа для оценки поведения пользователей e-commerce платформы. Основная задача — измерить удержание (Retention Rate) по количеству активных покупателей (user_id) и по сумме их покупок (общий доход), а также выявить закономерности возвращаемости клиентов.
🛠 Выполненные задачи
Предобработка данных: проверка на пропуски, подготовка таблиц транзакций и дат первых покупок пользователей.
Построение когорт: группировка пользователей по месяцам/периодам привлечения.
Расчет метрик удержания: расчет Retention Rate по количеству пользователей и объему выручки.
Визуализация: построение тепловых карт (heatmaps) удержания для наглядного анализа динамики когорт.
Интерпретация результатов: формирование выводов по поведению покупателей и рекомендаций для бизнеса.
